# Spring Core Lab 4

## About the Project

This is my Spring Core Lab 4 project. In this lab, I learned how to use the Spring Framework and how Spring manages objects and their dependencies.

## Technologies Used
- Java 19
- Spring Framework
- Maven
- Lombok
- IntelliJ IDEA

## How to Run
1. Open the project in IntelliJ IDEA.
2. Load the Maven dependencies.
3. Open App.java.
4. Run the application.
