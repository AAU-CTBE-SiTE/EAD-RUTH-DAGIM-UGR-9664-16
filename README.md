# Lab 2 – Java Application

## Description
This project contains the Java application developed for Lab 2 using Maven in Eclipse.

## Package
- com.craft

## Files
- App.java – Main application entry point.
- Student.java – Student class used in the application.

## Technologies Used
- Java
- Maven
- Eclipse IDE

## How to Run
1. Open the project in Eclipse.
2. Locate App.java inside the com.craft package.
3. Right-click App.java.
4. Select Run As → Java Application.
