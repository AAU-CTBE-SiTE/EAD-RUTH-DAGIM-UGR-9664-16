# Student Management RESTful CRUD API

A RESTful API built using Spring Boot, Spring Data JPA, and MySQL to manage student records.

## Technologies
- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Lombok

## Features
- Create a student
- Retrieve all students
- Retrieve a student by ID
- Update student information
- Delete a student

## Student Fields
- ID
- First Name
- Last Name
- Email
- Department
